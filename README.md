# assetflowstudio.com

Placeholder page for https://assetflowstudio.com/ (static, GitHub Pages, no build step). Rebuilt Oct 11, 2026.

- `brand/`: Asset Flow Studio logo system. `assetflowstudio-seal-*` (badge with name), `assetflowstudio-emblem-*` (badge only), `assetflowstudio-logo-*` (horizontal lockup). SVG (text converted to outlines) plus PNG rendered natively with resvg (seal and emblem 4096 px, lockup 5120 px wide; never upscaled). Web-sized PNGs (`-h64/128/192`, `-300…1380`, `-40/80/120`) are downsampled from those for crisp display via srcset. `-dark` is for dark backgrounds, `-light` for light backgrounds.
- `img/hero-3840.*`: hero photograph by Naira Babayan on Unsplash (https://unsplash.com/photos/water-falls-on-rocky-shore-during-daytime-ACwstNBeVjE), downsampled from the 4592x3056 original (never upscaled). Unsplash License.
